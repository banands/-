# Мостостроитель

Игра-головоломка в одном файле `index.html` (canvas, без библиотек): ставишь шарики, они соединяются палками, мост должен дотянуться до флажка.
Режимы: уровни (12 ручных + бесконечная генерация), уровень дня, бесконечный путь, мосты с тележкой (18), свои уровни из редактора.
Ещё: сталь (крепче, тяжелее, стоит 2 шарика), подсказка 💡 (бот в игре), синтезированные звуки, скины.

## Что где

| Путь | Что это |
|---|---|
| `index.html` | вся игра — открывается в браузере как есть |
| `android/template/` | содержимое APK 0.18 без подписи: манифест `ru.mostostroitel.game`, `classes.dex` (WebView-обёртка), иконки, шрифты |
| `android/fonts.css`, `android/migrate.js` | что добавляется в `index.html` внутри APK: локальные шрифты и перенос прогресса из APK 0.01 |
| `android/build_apk.py`, `android/Sign.java` | сборка и подпись APK |
| `tools/` | бот-строитель и проверки (Playwright + Chromium) |

## Сборка APK

```sh
KEYSTORE_PASSWORD=… python3 android/build_apk.py --version-name 0.20 --version-code 22 --keystore путь/к/mostostroitel-key.jks
```

Результат — `build/Mostostroitel-0.20.apk`. `versionCode` каждый раз должен расти, иначе телефон не поставит обновление: выпущенные версии записаны в `android/released.txt`
(скрипт сам дописывает туда новую после подписи и не даст собрать с кодом не больше уже выпущенного).
Подпись — схема v2 (minSdk 24), отпечаток ключа SHA-256 `D9:BA:BB:2E:…:1C:42:D3`. Ключ и пароль в репозиторий не кладутся (`.gitignore`).

## Проверки

Нужны Node и Playwright (`export PW=$(npm root -g)/playwright`). При ошибках на странице (в том числе пойманных игрой и выведенных в `console.error`) или проваленных проверках инструменты завершаются с ненулевым кодом.

- `node tools/fuzz.js index.html 90` — случайные ходы во всех режимах: исключения, NaN, битые палки.
- `node tools/solve.js index.html 12-149 out.json 4` — бот проходит уровни (номера здесь с нуля: `12-149` — уровни 13–150; два варианта бота, берётся лучший; уровни из `REROLL` — на своей «соли»); число шариков → норма `PAR`.
- `node tools/replay.js index.html 13,14` — ходы бота повторяются в свежей странице: победа, флажки, монетка.
- `node tools/view.js index.html out.png 13,15` и `node tools/shots.js index.html dir 844x390` — снимки уровней и экранов.
- `node tools/ui.js index.html` — сценарий через настоящие касания: меню, уровень, отмена, магазин, настройки, мост, перезапуск.
- `node tools/bridge_check.js index.html 11,12 2` — типовые фермы на мостах 11 и 12 (все мосты — `""` вместо списка) + проверка тележкой; по шарикам лучшей фермы (примерно ×1.2) подбирается норма `par` в `BLEVELS`.
- `node tools/daily_check.js index.html 365 3 out.json --reroll` — уровни дня на год вперёд, начиная с `DAILY0`; где бот не уложился в 40 шариков — другая «соль»; итог — строка `DAILY` (норма + соль на каждый день с 3.10.2026 по 2.10.2027).
- `node tools/endless_check.js index.html 40` — участки бесконечного пути с новинками как мини-уровни.

## Уровни с 13-го

Генератор `genLevel` детерминирован по номеру уровня. Кроме пропастей, ступеней и столбов в нём есть:
летающие острова, ямы с шипами на дне, шипы на краю площадки, скалы сверху и бонусная монетка (+5, один раз на уровень).
Каждая новинка сначала появляется одна на обучающем уровне (13 — остров, 14 — монетка, 15 — яма, 17 — шипы, 19 — скала)
с подсказкой; подсказка показывается один раз (`prog.seen`).
Уровни 13–150 проверены ботом (все проходимы, самый тяжёлый — 27 шариков); нормы на три звезды (`PAR`) — результат бота ×1.1,
после 150-го — формула по длине, подъёму и новинкам, подобранная по тем же результатам.
Если уровень оказался слишком тяжёлым (больше 27 шариков у бота), генератор берёт для него другую «соль» (`REROLL`):
`REROLL_MAX=6 node tools/solve.js …`, затем `node tools/par.js index.html res.json --write` (уровни, которых нет в результатах или где бот не прошёл, сохраняют прежние норму и соль).

## Уровень дня, подсказка, сталь, редактор

- **Уровень дня** — `dailyLevel(день)`: тот же генератор с фиксированной средней сложностью, 1–2 новинки и монетка; у всех один и тот же.
  Рекорд — по шарикам, +15 монет за первое прохождение за день, серия дней подряд (`prog.daily`).
- **Подсказка** — `hintGen()`: облегчённый `tools/bot.js` внутри игры, прогоняет физику на копии в режиме `sim` (без звука, флажков и прогресса),
  считает по ~12 мс за кадр. 3 бесплатно (`prog.hints`), дальше 10 монет. На мостах нет.
- **Сталь** — шарик `m=2`, палки `st` с порогом ×2.2; решатель делит поправку по массам только если сталь есть — дерево считается как раньше.
- **Редактор** — уровни хранятся в `prog.custom` кодами `MS1…` (base64 от JSON, координаты /5); код от друга проверяется и зажимается в пределы.
